## cacerts-der2pem v2.0.0（预发布 / Pre-release）

AlwaysTrustUserCerts 的独立补充模块：校验已经注入的 CA，将受支持的可写 tmpfs 目录中的 DER 转换为 PEM。保留同一证书与 SHA-256 指纹，不新增 CA，不替代上游模块，不绕过 pinning。

### 支持与验证

- 实现最低要求 Android 8 / API 26+。
- Android 15 + KernelSU + AlwaysTrustUserCerts v1.3：隔离文件及私有挂载测试通过。
- Magisk：已实现 BusyBox 路径查找，未真机验证。
- 仅支持服务可见的 system / Conscrypt APEX 可写 tmpfs 目录挂载；不支持单文件 bind 或只读目录。
- **尚未完成新版完整安装、重启持久化及业务 HTTPS 验收，因此标为预发布。**

### 安装

保持 AlwaysTrustUserCerts 启用，从下方 Assets 下载 **cacerts-der2pem-v2.0.0.zip**，在 KernelSU 管理器中安装并重启。不要安装自动生成的 Source code ZIP。校验：`shasum -a 256 -c SHA256SUMS`。

详细原理、兼容限制、验收和回退方式见 README / README.zh-CN.md。

### English

An independent format-normalization companion for AlwaysTrustUserCerts. Validates existing X.509 certificates, stages PEM with metadata and backups, and publishes each conversion atomically. Includes recurring boot-completed scans and explicit-PID verification. No CA is bundled or added.

Android 15 + KernelSU + AlwaysTrustUserCerts v1.3 isolated tests passed. Android 8+ is the implementation minimum; Magisk lookup is implemented but untested. Full installation/reboot and application HTTPS validation remain outstanding. Install the named module ZIP asset, not the source-code archive.
